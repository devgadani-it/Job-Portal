# Job Portal

A responsive job portal web application that helps job seekers discover opportunities and submit applications online, and lets companies manage listings.

## Features
- Job search and category-based filtering
- User authentication (login/logout)
- Application forms with resume upload
- Client-side form validation
- Company-specific pages (Google, Apple, Amazon, Meta, Microsoft, Uber, Wipro, and more)
- Responsive layouts with dynamic JavaScript interactions and CSS animations

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript, Bootstrap

## Project Structure
```
Project/
├── job_portal.html       # Main job listings page
├── job_portal.css
├── job_portal.js
├── login.html
├── logout.html
└── company/              # Company-specific pages (apply, contact, policies, etc.)
```

## Running Locally
Just open `job_portal.html` in a browser, or serve the folder with any static server:
```bash
npx serve .
```
